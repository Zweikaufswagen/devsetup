## Entwicklungsumgebung

Windows mit installiertem [devsetup](https://github.com/Zweikaufswagen/devsetup).
Im Projektordner:

```text

```

VSCodium öffnet den Devcontainer. Das Projekt bleibt auf Windows gespeichert und
ist im Container unter `/workspaces/project` eingebunden.
